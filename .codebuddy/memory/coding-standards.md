# CodeBuddy 统一代码规范 v1.0

> 适用范围：Java / Go / Python / JavaScript/TypeScript / SQL / Shell / Dockerfile / Nginx

---

## 一、通用命名规范

| 类型 | 规则 | 示例 |
|------|------|------|
| 变量 | 小驼峰 lowerCamelCase，禁止拼音、无意义单字母（i/j循环除外） | `userName`, `orderList` |
| 常量 | 全大写下划线 UPPER_SNAKE_CASE | `MAX_RETRY_COUNT` |
| 类/结构体 | 大驼峰 UpperCamelCase | `UserService`, `OrderDTO` |
| 函数/方法 | 小驼峰，动词开头 | `getUserById()`, `sendMessage()` |
| 数据库表 | 蛇形小写 snake_case，复数表名 | `order_items`, `user_logs` |
| 数据库列 | 蛇形小写，禁止关键字命名 | `created_at`, `is_deleted` |
| 文件名 | 类文件大驼峰，脚本/工具文件小驼峰或下划线 | `UserController.java`, `deploy.sh` |

---

## 二、通用格式规范

- **缩进**：统一 4 空格，禁用 Tab
- **行宽**：单行最大 120 字符，超长换行拆分
- **空行**：方法、类、逻辑块之间空一行，连续空行最多 1 行
- **大括号**：左大括号同行，右大括号独占一行
- **空格**：运算符两侧、逗号后必须加空格，括号内侧无空格

---

## 三、注释规范

- **文件头部**：必须标注用途、创建人、修改时间、核心能力
- **类注释**：文档注释说明功能、入参、出参、异常
- **方法注释**：公共方法必须写文档注释；私有方法复杂逻辑加行注释
- **行内注释**：仅解释复杂业务逻辑，不注释显而易见代码，禁止冗余注释
- **TODO 格式**：`// TODO: 责任人-截止时间-待优化内容`

---

## 四、安全规范

1. 禁止硬编码密钥、账号、token、数据库地址
2. 入参必须做校验、参数脱敏输出
3. SQL 禁止字符串拼接，统一使用预编译
4. 接口禁止返回敏感字段（手机号、身份证、密码明文）
5. 禁止执行系统命令拼接外部输入，防注入

---

## 五、性能规范

1. 循环内禁止数据库查询、IO 操作
2. 大列表分页查询，禁止全量加载
3. 合理使用缓存，避免频繁重复计算
4. 释放连接、文件句柄、线程资源，避免内存泄漏
5. SQL 必须建立索引，禁止 `SELECT *`

---

## 六、可复用性规范

1. 重复逻辑抽离工具类/公共函数，禁止复制粘贴代码
2. 常量统一抽常量类/配置文件，不写魔法数字、魔法字符串
3. 复杂分支使用策略模式、枚举替代 if-else 嵌套
4. 组件高内聚低耦合，单一职责原则

---

## 七、Java 专项规范（SpringBoot）

- **分包**：严格分层 `controller/service/mapper/entity/util/config`
- **实体类**：使用 Lombok，不手写 get/set，数据库映射注解规范
- **异常**：统一全局异常处理器，自定义业务异常，禁止直接抛 RuntimeException
- **SQL**：MyBatis/MyBatis-Plus，禁止动态 SQL 拼接字符串
- **线程**：禁止手动创建 Thread，统一使用线程池，参数可配置

---

## 八、SQL 专项规范

- **关键字**：关键字大写 `SELECT/FROM/WHERE/JOIN`
- **JOIN**：显式 `INNER JOIN`/`LEFT JOIN`，禁止隐式逗号关联表
- **DELETE/UPDATE**：必须带 WHERE 条件，禁止无条件全表操作
- **索引**：关联字段、查询条件必须建索引，避免索引失效函数
- **事务**：更新多表必须加事务，控制事务粒度

---

## 九、Shell 专项规范

- **兼容性**：基础语法，不使用高级 bash 特性如 `fi` 简化写法
- **日志**：区分控制台输出/文件输出，可配置开关
- **入参校验**：脚本入参强制校验，缺失参数提示帮助文档
- **错误处理**：`set -euo pipefail` 开启严格报错，异常捕获输出日志

---

## 十、前端 TypeScript 专项规范

- **类型**：所有变量、接口、返回值强制定义 Type 类型，禁用 `any`
- **API**：统一封装请求工具，统一错误拦截、状态码处理
- **组件**：组件拆分，单一功能组件，props 类型严格约束
- **样式**：使用 scoped 样式，全局样式统一管理，禁止行内大量 style

---

## 十一、交付规范

- **输出**：输出完整可运行单文件代码，附带调用示例、测试用例
- **说明**：代码后分三段说明：核心逻辑、依赖配置、部署/调试命令
- **风险**：自动识别潜在风险，输出风险点 + 修复方案
- **修改**：修改代码时标注变更行号，对比新旧逻辑，说明改动原因
